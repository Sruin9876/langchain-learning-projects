# CSV Data Analyst (Gemini + modern LangChain)

Ask questions about a CSV in plain English. The app uses pandas for deterministic operations and a LangChain agent (`create_agent`) to choose from a small set of analysis tools. It does **not** execute arbitrary Python generated by the model.

## Features

- Upload a CSV or load `sample_data/employees.csv`
- Preview rows and inspect dataset shape
- Ask questions about row counts, column summaries, filters, grouped statistics, and numeric correlations
- Gemini 3.5 Flash-Lite by default (configurable through `GEMINI_MODEL`)
- Fixed tools over pandas; no Pandas Python REPL agent

## Setup (Windows / PowerShell)

Run from the `langchain-projects` workspace root using the shared environment:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r .\07_csv_data_analysis\requirements.txt
Copy-Item .\07_csv_data_analysis\.env.example .\07_csv_data_analysis\.env
notepad .\07_csv_data_analysis\.env
streamlit run .\07_csv_data_analysis\app.py
```

Put your real Google AI Studio key after `GOOGLE_API_KEY=` in `.env`. Keep the `.env` file private and out of GitHub.

## Example questions

- How many rows and columns are in this file?
- Summarise the `SALARY` column.
- Show rows where `SALARY` is greater than `8000`.
- Count employees by `DEPARTMENT_ID`.
- Calculate average `SALARY` by `DEPARTMENT_ID`.
- Which numeric columns are correlated?

Use exact column names when possible. The built-in tools support a finite set of operations; arbitrary multi-step analyses may not be supported yet.

## How the app works

1. Streamlit reads the CSV into a pandas DataFrame.
2. `create_agent` from modern LangChain creates an agent loop.
3. The model chooses one or more defined tools based on the question.
4. Tools perform constrained pandas calculations and return small text results.
5. Gemini explains those results in plain language.

## Limitations and privacy

- The app sends the user’s question and tool results to the Gemini API. Do not use confidential/sensitive data unless you are authorised to share it with the provider.
- It is intentionally safer than the original `create_pandas_dataframe_agent` approach, which requires enabling Python code execution and can run arbitrary model-generated code.
- The toolset supports dataset overview, one-column summary, basic row filtering, grouped aggregations, and numeric correlation. Extend `build_dataframe_tools()` to add more operations.
- Very large CSVs may be slow; try a smaller subset for the learning project.

## Troubleshooting

- **API key not detected:** ensure `.env` is beside `app.py` inside `07_csv_data_analysis`, and the variable is named `GOOGLE_API_KEY`.
- **Model error:** change `GEMINI_MODEL` to a currently available model in Google AI Studio.
- **Quota or connectivity errors:** verify the key, API access, network connection, and model-specific quota.
